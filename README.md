# stacksonstacks-1.20.1forge
只是拙劣的模仿原作者的模组罢了
正如标题所说：模组适用于1.20.1forge
这个模组暂时只能放置铁锭，金锭，铜锭，下届合金锭，绿宝石，钻石，青金石，紫水晶
可以通过H开启或者关闭矿石放置功能

原版模组是是通过模型，而我不会，是通过拉伸铁块渲染的
